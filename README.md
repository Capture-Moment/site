# CaptureMoment - Official Website
Official website of CaptureMoment, free photo-editing software. Learn about the project, see screenshots of the software, and download the latest version for Windows, macOS, and Linux. A photographic moment, captured freely.

**Live site:** https://capture-moment.github.io/repository-name/

## About this repository

This repository contains only the official website of CaptureMoment: a single page that presents the project, shows the software in pictures and provides download links for the latest release.

The software itself lives in a separate repository: [Capture-Moment/CaptureMoment](https://github.com/Capture-Moment/CaptureMoment).

## Site overview

- Single-page site: presentation, screenshots, features, download and contact sections
- The whole site fits in one `index.html` file (HTML, CSS and JavaScript), with no build step and no framework
- Available in English and French with a one-click language switcher
- Free hosting via GitHub Pages

## Repository structure

```

└── asset/

    ├── favicon.png   # Browser tab icon
    └── home.png      # Screenshot of the main window
```

## Publishing

The site is deployed with GitHub Pages:

1. Open **Settings**, then **Pages**
2. Under **Build and deployment**, select **Deploy from a branch**
3. Choose the `main` branch and the `/ (root)` folder, then save

Every push to `main` updates the site automatically within a minute.
